## 未提交工作 A：NHTSA lease／原子發布

### 已落盤

- migration 024：single-writer lease、scheduler lineage 與 current artifact provenance。
- `NhtsaRunLease`、64 位 token、lease expiry／heartbeat CAS。
- scheduler parent→child→domain run 的直接 lineage。
- bulk／API／VIN publish、domain completed、scheduler child completed 的原子交易。
- 所有 intermediate artifact mutation 要求 active lease。
- `_assert_active_lease` 先取得 domain row lock，再用新 DB statement timestamp 驗證 expiry。
- finalize 在取得有效 lease lock 後可跨 TTL 完成；失敗仍整筆 rollback。
- Bulk／API／VIN publish 前會停止 heartbeat並 bounded join。
- heartbeat DB connect／read／write timeout 15 秒，join timeout 20 秒。
- heartbeat enter／close／join 失敗會 fail closed；cleanup error 不遮蔽原始 exception／cancel。
- scheduler `_record_finish()` 採 domain→child lock order；已提交的 completed tuple 是權威，晚到
  非零 OS exit 只記診斷，不反向破壞一致狀態。

### 根因

run 5 已有 exact 10,000 membership，但仍有兩個 `crawl_state=error`。既有 resolver 會續用 run 5；
crawler 計算 remaining=0，無法再取得額度修復 failed scope，因此會永久重試，不能產生正式發布。

### 已落盤草稿

- `src/partsouq_catalog/repositories.py`
- `tests/test_partsouq_bounded_limit.py`

草稿在 resume SELECT 新增 `exhausted_with_failures`：當 membership 已達 target 且仍有 scope error，
舊 run 會 fail-closed 將 evidence 標成 rejected、清除 seal，並回傳 `None`，讓 scheduler 建立新的
logical run。它不刪除舊 raw parts、artifact 或 lineage。
