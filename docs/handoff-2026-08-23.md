### 最新獨立審查：3 個 P1

1. **304 reuse 繞過 parser-version 與 raw integrity gate。**
   `nhtsa/service.py` 與 `nhtsa/api_service.py` 在 304 時會直接重用 artifact。parser 升版但
   ETag不變時，新 parser永遠不會重匯；raw檔遺失會永久 304→FileNotFound；raw被改寫時
   也未重新核對 DB size／SHA-256。送 conditional header前必須先驗 parser version、檔案
   存在、大小與 hash；不合格改用 unconditional download。
2. **migration 024 legacy recovery 用秒級時間完全相等配對。**
   run key timestamp先產生，scheduler row後寫入，跨秒就無法配對，migration會被兩筆
   running run永久擋住。需改成有界時間窗＋唯一配對，補 cross-second／ambiguous E2E。
3. **hard-kill留下 running child＋expired domain時無法自動回收。**
   preflight目前只接受 child已是 failed；斷電後 child/domain都 running會讓 migration永久
   fail-closed。只可在足夠老、lease逾期、lineage唯一時，同交易將 child failed、domain
   interrupted；active／recent／ambiguous仍須拒絕。
