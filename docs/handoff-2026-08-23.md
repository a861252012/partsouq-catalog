## 待完成事項與建議順序

### P0-1：NHTSA lease／發布原子性與 stale recovery

先處理，因 stale `running` 已阻擋 catalog migration 023。

1. 為 NHTSA run 加入 scheduler 關聯、lease token、heartbeat、lease expiry。
2. claim／heartbeat／finish 使用 token CAS；失去 lease 的 worker 不得 publish。
3. artifact current publish、run completed 與 scheduler completed 必須同一交易，失敗全部 rollback。
4. recovery 只能在「唯一且可證明對應的 scheduler child 已終止」時標 interrupted；不可把
   舊 run 人工改 successful。
5. 補 MySQL crash／timeout／duplicate worker／publish-before-finish mutation tests。
6. Scheduler parent／child 必須用直接 FK 或明確欄位連結；正式 runtime 不得繼續只靠
   run-key regex、時間推測或 output marker。
7. `publish current`、domain run completed、scheduler child completed 必須同一交易，或有
   可證明等價的原子協定；既有「先發布、再 finish」測試契約必須反轉。
