## 尚未提交的 NHTSA 整合稿

### 已落盤的程式內容

- `NhtsaRunLease` 包含 run id、64 位 token 與 scheduler run id。
- `start_run` 核對 matching、running 的 scheduler child；有 parent 時也核對 NHTSA parent。
- 單一 writer lease、過期 lease takeover。
- heartbeat／finish 使用 token、status、expiry CAS。
- DB heartbeat 使用獨立 MySQL connection。
- bulk／API／VIN 的 current publish、domain run completed、scheduler child completed 改成同一交易。
- `nhtsa_current_artifacts` 記錄 `published_run_id`。
- commit 失敗 rollback；lease 遺失禁止 publish。
- CLI 強制要求正整數 `SCHEDULED_JOB_RUN_ID`。
- scheduler parent／bulk／API child 使用直接 parent link。
- child exit 0 會核對 exact linked domain run 已 completed 且 lease 已清除。
- child failure 只中斷 exact linked running domain run，不再用 run-key regex 或 output marker 廣播。
- recovery 使用 parent→child→domain→current artifact 的直接 lineage。
- scheduler-only cleanup 仍會把超齡、尚未 claim domain 的 orphan child，以及沒有 active child 的
  超齡 parent 標 failed；它不會修改 domain run。整合 review 時要再確認這項政策符合預期。
